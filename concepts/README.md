# What’s a *Database*?

***Databases*** are a way to organize and save - or ***persist*** - data.

There are many different database systems - check out [**this site**](http://db-engines.com/en/ranking) that tracks the popularity of different database systems.

As you can see, **Relational Database Management Systems (RDMS)** are by far the most popular - they’ve been around since the 1960s. They are more commonly referred to as **SQL Databases** because they are designed and accessed using **Structured Query Language (SQL)**.

However, you’ll also see that **MongoDB** is by far the most popular **NoSQL** database system.

There are several varieties of NoSQL databases. MongoDB is of the **document-based** variety because it stores and retrieves *documents*.

# More About *MongoDB*

***MongoDB*** is an open-source NoSQL database that stores data in an unstructured, JSON-like documents.

MongoDB puts the **“M”** in the MEN/MERN stacks. These technology stacks emphasize the use of JavaScript on both the **front** and **back**-ends.

Instead of **SQL** (***Structured Query Language***), MongoDB uses JavaScript as its native language for database operations.

You’re going to see that working with **data** in MongoDB is like working with JavaScript objects.
